# Données d3-celestial

- Source : d3-celestial, Olaf Frohn, dépôt GitHub `ofrohn/d3-celestial`, dossier `data/`,
  branche `master`, fichiers téléchargés le 2 novembre 2026 :
  - `constellations.lines.json` : figures des constellations (coordonnées RA/Dec J2000 en degrés,
    RA dans [−180, 180]), 89 entités (Serpens apparaît en deux parties, tête et queue).
  - `constellations.json` : noms (latin, génitif, anglais, français et autres langues),
    position du libellé, rang.
  - `constellations.bounds.json` : limites officielles UAI (prévu pour la v2).
  - `messier.json` : objets de Messier (prévu pour la v2).
